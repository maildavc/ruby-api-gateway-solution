# Getting Started

Welcome to the Gapeiro API Gateway.

## Create your first app

1. Navigate to **Apps** and click **Create App**.
2. Choose an environment (Sandbox is recommended).
3. Generate an API key and save it securely.

## Quick health check

```bash
curl -H "x-api-key: <your_key>" https://api.gapeiro.dev/health
```
